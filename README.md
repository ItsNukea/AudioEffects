# Audio Effects

Welcome to the Audio Effects page:<br>
Audio Effects is a lightweight program that lets you perform some audio effects on some audio files. (Who could've guessed)<br>

This is a project I made for school, so don't expect too much from it, except maybe some crashes and/or by wonder, a feature that _does_ work

## Installation guide

### Requirements
- Windows, it's a school project as I said, don't expect too much from it
- A brain (optional)

### Via Releases
Go to the Releases tab on the middle right of the screen or click [here](https://github.com/ItsNukea/AudioEffects/releases), download the latest version and run it. The installation wizard will guide you through the rest.<br>
_Congratulations!, you just installed Audio Effects_

### Via raw file
Go to [here](https://github.com/ItsNukea/AudioEffects/blob/main/installer/Audio%20Effects-1.0.exe), press 'download raw file', execute it and The installation wizard will guide you through the rest
